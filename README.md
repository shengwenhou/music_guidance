# 聽見馬勒｜全曲導聆

[開啟網站](https://shengwenhou.github.io/music_guidance/)

[開啟馬勒第八號導聆](https://shengwenhou.github.io/music_guidance/mahler8/)

馬勒第二號交響曲《復活》五樂章的繁體中文互動導聆。原始YouTube演出搭配 **499段字幕**，通常每10秒更新，章節交界立即切換。背景故事與聆聽提醒交替，涵蓋創作、文本、曲式、音色及全曲關聯。

## 使用

按「開始全曲導聆」，或選擇樂章、拖動時間。字幕顯示在影片下方，使用網頁的「影片＋字幕全螢幕」一起放大；YouTube自己的全螢幕只放大影片。可重聽10秒、上一段／下一段、預覽字幕；展開完整背景可查看資料來源。

| 樂章 | 官方影片起點 | 內容 |
| --- | --- | --- |
| I | 00:00 | 葬禮、六年創作歷程、器樂對比 |
| II | 22:18 | 蘭德勒、回望生活、聲部與舞步 |
| III | 31:39 | 向魚說教、少年魔號、諷刺與徒勞 |

| V | 48:06 | 復活、幕後樂團、Klopstock與馬勒的文字、獨唱與合唱 |

## 核對程度

五個樂章起點與演出資訊來自ARD Klassik官方影片說明。本片約82:56。章內的10秒是閱讀節奏，**未逐小節驗聽校準**；「當你聽見」「稍後」是段落預告，不是已驗證的樂器入點；歌詞對時另外標示。第四樂章開頭有人聲，其餘獨唱、鳥鳴、合唱與末段樂器以聆聽線索呈現。全曲版完成的是背景與區段導聆，不宣稱精確的主題辨識。

音樂由YouTube提供，廣告、緩衝、地區或裝置限制可能影響播放。本專案沒有下載或重製演出功能。

## 本機執行與驗證

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
node --check dist/guide-data.js
node --check dist/app.js
node --check dist/lyrics-data.js
node --test tests/guide.test.cjs
```

開啟 http://127.0.0.1:8765/ 。不要以file://直接開啟，缺少HTTP Referer可能導致YouTube錯誤153。GitHub Actions檢查腳本、執行互動測試，再發布dist至GitHub Pages。

## 馬勒第八號《千人交響曲》

同一網站另有以 Mariss Jansons／皇家大會堂管弦樂團 2011 年演出製作的獨立全曲頁。影片長 86:33，包含 **521段通常每10秒更新的背景／聆聽字幕**、重要人聲與器樂進場提醒，以及 **377段同步繁體中文歌詞**。

- 第一部：拉丁文《Veni Creator Spiritus》原文，可切換顯示。
- 第二部：歌德《浮士德》第二部終幕德文原文，可切換顯示。
- 中文為本專案依公版原文重新翻譯；沒有採用影片中的鄒仲之中文字幕。
- 時間界線依同一YouTube影片的拉丁文／德文字幕軌與章節資料；複調重疊處以主要或最先進入的文字呈現。
- 另提供 `dist/mahler8/mahler8-zh-Hant.vtt` 下載；無TTS。

程式碼與原創中文導聆／翻譯採MIT；影片、錄音、原字幕軌及第三方資料不在MIT授權範圍。

## 第五樂章進場前提醒

獨立的文字提示列會在預告區間顯示，全螢幕也可見，不打斷音樂。四處提示：49:35遠距圓號；61:50幕後打擊與小號；65:55大召喚；79:20管風琴。這些是保守提前的影片區段估計，未逐秒驗聽，不是精確倒數。樂譜身份與位置分別依Banks、Trout的演奏研究，以及1897版總譜核對。管風琴在排練號48／第712小節隨最後強奏合唱加入，而非等合唱結束。

首卡另修訂：Banks線上跋與主目錄對《葬禮》名稱的年代有歧異，因此不把1891年當成最早用名的無爭議定論。


## 終章中文歌詞（同場錄音對時）

中文為本專案依Klopstock與馬勒德文原詞所作的新譯，含終章獨唱與合唱。歌詞與10秒導聆是獨立軌道；依樂句切換，提供中文開關、可選德文、±30秒歌詞微調、中德對照索引與VTT下載。

時間使用ARD同場官方錄影音訊，以已知德文文本的強制對齊初稿為底，再逐句對照頻譜、長音、休止與樂句修正，共32組字幕。五個樂章起點與YouTube相同；ARD在82:04左右音樂收束、82:16左右開始掌聲，YouTube多出的約10秒位於尾端，因此歌詞無須整體平移。先前未對時的最後四句已補齊；複調合唱以最先可辨識的聲部換句，聲部重疊處仍可能有約1–2秒差異。

- `dist/lyrics-data.js`：初校時間、翻譯、待對時文字與方法。
- `dist/mahler-finale-zh-Hant.vtt`：同一初稿時間的中文歌詞。
- `scripts/finale-translation.json`：德文分句與本專案中譯。
- `scripts/finale-timing.json`：同場錄音逐句時間與複調處理註記。
- `scripts/build-lyrics.py`：由翻譯與時間資料建立歌詞資料／VTT。

演出音訊和模型權重不放入儲存庫或網站；網站仍只使用YouTube原播放器。翻譯為原創，可依專案MIT使用；錄音及第三方著作另依其權利。
